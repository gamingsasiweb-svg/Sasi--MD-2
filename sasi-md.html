Setup Guide
How to Connect
01

Open the Pair Code section

Click Pair Code in the nav above to jump to the generator.

02

Enter your WhatsApp number

Type your full number with country code — no + sign. Example: 94756XXXXXX for Sri Lanka.

03

Click Generate

An 8-digit code appears within a few seconds.

Code valid for ~60 seconds
04

Open WhatsApp → Linked Devices

Tap the 3-dot menu → Linked Devices → Link a Device → Link with phone number.

05

Enter the code

Type the 8-digit code. Your bot session links automatically.

06

Copy your Session ID

Your Session ID appears on screen. Copy it into your bot's config file and you're live.

Session saved to database
